# Portfolio setup

## Run locally

```sh
npm install
npm run dev
```

## Tailwind CSS

This project uses Tailwind CSS v4. Keep `@import "tailwindcss";` in `src/index.css` and the `@tailwindcss/vite` plugin enabled in `vite.config.js`. Restart the dev server after changing Vite configuration.

## Supabase

Create a `.env` file in the project root (next to `package.json`) with your Supabase project's **Project URL** and **anon/public key**:

```env
VITE_SUPABASE_URL=https://your-project-id.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-public-key
```

In the Supabase SQL Editor, create the `portfolio_items` table with columns matching the app:

```sql
create table public.portfolio_items (
  id bigint generated by default as identity primary key,
  title text not null,
  category text not null,
  tools text not null,
  description text not null default '',
  image_url text not null,
  created_at timestamptz not null default now()
);
```

Configure Row Level Security policies for the operations you intend to allow. The browser app should only use the anon/public key; never put a `service_role` key in a `VITE_` variable. After changing `.env`, restart `npm run dev`. The app shows sample projects when Supabase is unavailable and displays the connection error in the sidebar.
